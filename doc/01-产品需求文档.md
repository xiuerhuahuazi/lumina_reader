## 1. 产品定位与价值主张

**Lumina Reader** 是一款本地优先的 RSS/Atom 阅读器，整体感受应像一间**安静的私人阅览室**：信息密度可调、视觉噪音极低、操作轻盈流畅。

### 1.1 核心价值

- **沉浸阅读**：深色默认主题、窄栏居中正文、可选焦点模式屏蔽干扰。
- **掌控信息**：三栏布局快速扫读；多种列表视图；键盘全流程操作。
- **本地智能**：无需联网即可完成分组、标签、摘要（v0.3+）；数据默认留在设备。
- **可靠离线**：PWA 安装后，壳与近期文章可完全离线阅读。

### 1.2 设计参考

UI 概念稿见 [assets/ui-mockup-overview.png](./assets/ui-mockup-overview.png)，分区编号 P1–P9 贯穿全部设计文档。

## 2. 目标用户与典型场景

| 用户类型 | 典型场景 |
|----------|----------|
| 深度阅读者 | 每日集中阅读长文，使用焦点模式与字号调节 |
| 研究者 / 写作者 | 高亮关键段落、写批注、导出带标注文章 |
| 信息工作者 | 快速扫读多源资讯，用智能分组与今日摘要过滤噪音 |
| 独立开发者 | 导入 OPML、自托管、关注隐私与离线可用性 |

## 3. 术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| 订阅源 | Feed | RSS/Atom 源，含名称、URL、图标、更新状态 |
| 文章 | Article | 单篇订阅内容，含标题、摘要、正文、元数据 |
| 智能分组 | SmartGroup | 由规则或本地 AI 聚合的文章/源集合 |

| 稍后读 | ReadLater | 标记待读，不改变已读状态 |
| 阅读进度 | ReadingProgress | 文章滚动位置百分比 |

## 4. 全局视觉规约

### 4.1 设计原则

- 避免纯黑 `#000` 与纯白 `#fff`。
- 不使用阴影、卡片化区块、旋转加载器、emoji 图标。
- 栏目间以 **1px 半透明分隔线** 划分，无区块阴影。
- 强调色 **不大面积铺开**，仅用于状态与交互提示。

### 4.2 主题色值

| `--text-primary` | `#e6e4df` | 正文、标题 |

### 4.3 强调色使用边界

`#8bb8b0`（暖黄/冷白主题使用对应变体）**仅用于**：

- 未读文章左侧 3px 指示线
- 列表项选中态边框/背景微亮
- 超链接下划线
- 已读切换后的短暂反馈闪烁
- 高亮文本背景（半透明）
- 主操作按钮（如「导入」）— 单屏最多 1 个主按钮

**禁止用于**：大面积背景、装饰条、图标填充色块。

### 4.4 字体

| 层级 | 字体 | 说明 |
|------|------|------|
| 界面全局 | Inter，fallback 系统无衬线 | 侧栏、列表、按钮、设置 |
| 正文默认 | Merriweather，备选 Lora | 阅读面板文章区 |
| 正文可选 | Inter / 系统无衬线 | 用户可在设置中切换 |

### 4.5 字号与行高（三档）

| 档位 | 正文字号 | 行高 | 界面字号 |
|------|----------|------|----------|
| 小 | 15px | 1.6 | 13px |
| 中（默认） | 17px | 1.7 | 14px |
| 大 | 19px | 1.8 | 15px |

阅读面板标题：正文字号 × 1.75，字重 600。

### 4.6 图标

- 极简线性 SVG，线宽 **1.5px**。
- 颜色与当前 `--text-primary` 一致。
- **无填充色块**，不使用 emoji。

### 4.7 禁用项清单

- 投影阴影（`box-shadow` 装饰性使用）
- 卡片式圆角容器包裹列表项
- 纯黑/纯白背景或文字
- 旋转 Spinner 加载器（改用骨架屏）

## 5. 布局系统

### 5.1 桌面端三栏（≥1024px，对应 P1）

```
┌──────────────┬────────────────────┬─────────────────────────────┐
│  左侧栏      │  文章列表栏         │  阅读面板                    │
│  默认 220px  │  最小 340px         │  弹性宽度，正文 max 720px 居中 │
│  可拖拽调整  │  可拖拽调整         │  独立滚动                    │
└──────────────┴────────────────────┴─────────────────────────────┘
```

| 区域 | 规格 |
|------|------|
| 左侧栏 | 默认宽度 220px；最小 160px；最大 320px；拖拽把手 4px；完全折叠后仅留 **2px 悬停热区**，悬停 200ms 后展开 |
| 文章列表 | 最小宽度 340px；顶部固定工具栏（搜索、视图切换、仅未读开关） |
| 阅读面板 | 占剩余宽度；内容区 `max-width: 720px` 水平居中；左右 padding ≥48px（随宽度自适应） |
| 分隔线 | `1px solid var(--border)`，无阴影 |

### 5.2 移动端单栏（<768px，对应 P4）

- 单栏全宽展示当前主视图。
- 底部固定三入口：**订阅** | **列表** | **阅读**，高度 56px + 安全区。
- 向上滚动列表/阅读内容时，底部栏向下滑出隐藏；停止滚动或反向滚动 300ms 后恢复。
- 顶部：应用名 + 搜索图标（点击进入搜索全屏）。

### 5.3 平板（768px–1023px）

- 默认两栏：列表 + 阅读；左侧栏以抽屉覆盖层呈现。
- 可通过按钮或边缘滑出手势打开订阅侧栏。

## 6. 左侧栏（订阅与组织）

对应 P1 左侧区域。

### 6.1 结构

1. **智能分组**（上部，可折叠标题）
   - 每项：名称 + 未读计数（右对齐数字）
   - 默认项：今日摘要、技术前沿、深度长文、轻快简讯（v0.3 AI 生成，v0.1 仅手动规则）
2. **原始源**（中部，可折叠标题）
   - 每项：Favicon（16×16）+ 名称 + 未读计数
   - 状态指示见 §11
3. **标签云**（底部）
   - 横向排列，淡色小字（`--text-muted`），点击过滤文章列表

### 6.2 交互

- 点击分组/源：文章列表过滤至该集合。
- 右键/长按源：重命名、移除、查看错误详情、手动刷新。
- 底部「+」或设置入口：添加订阅、导入 OPML。

## 7. 文章列表

### 7.1 顶部固定栏

| 元素 | 行为 |
|------|------|
| 搜索框 | 占位符示例：「Search for articles on system design」；支持自然语言过滤（v0.3） |
| 视图切换 | 紧凑列表 / 摘要卡片 / 标题流，200ms 渐隐切换 |
| 仅显示未读 | Toggle 开关，默认关闭 |
| 全部标为已读 | 文字按钮，需二次确认（内联，非弹窗） |

### 7.2 今日摘要专区（列表顶部）

- 可折叠区块，默认展开。
- 展示过去 24 小时内未读且被标为「重要」的文章生成的 **≤3 句** 连贯摘要（v0.3）。
- v0.1：展示该时段未读文章标题列表，无 AI 生成句。

### 7.3 三种列表视图

#### 紧凑列表（默认，P1）

| 字段 | 规则 |
|------|------|
| 未读指示线 | 左侧 3px 宽，`--accent`；已读后 `transparent` |
| 标题 | 单行，超出省略；字重 500（未读）/ 400（已读） |
| 来源 + 时间 | 标题下第二行，`--text-secondary`，格式「来源名 · 相对时间」 |
| 摘要 | 第三行起最多 1 行摘要首句，`--text-muted` |
| 星标 | 右侧线性星形图标，已星标填充描边 accent |

行高：紧凑，约 72–88px/项（含 padding）。

#### 摘要卡片（P1 视图切换示意）

- 两列网格（窄屏单列）。
- 每卡片：缩略图（若有，16:9，max-height 120px）、标题（最多 2 行）、摘要（2 行）、来源 + 日期。
- 无卡片阴影，以 1px 边框分隔。

#### 标题流

- 仅标题连排，行高约 40px。
- 适合快速过滤与扫标题。

### 7.4 列表项交互

| 操作 | 桌面 | 移动 |
|------|------|------|
| 单击 | 在右侧阅读面板载入文章 | 进入阅读全屏视图 |
| 双击 | — | — |
| 长按 / 右键 | 上下文：稍后读、标为已读、加星、打开原文 | 同左 |
| 右滑 | — | 露出「稍后读」「标记已读」（P7），阈值见交互文档 |
| 拖拽多选 | 按住 Shift 或拖拽复选框进入多选模式 | 长按进入多选 |

批量操作：标为已读、加星、移至稍后读。

### 7.5 滚动自动已读

- 列表滚动时，**离开视口超过 2 秒** 的文章可自动标为已读（可配置，默认开启）。
- 设置项文案：「Automatically mark as read when scrolling」（P5）。

## 8. 阅读面板

对应 P2、P3、P8、P9。

### 8.1 载入与过渡

- 点击列表项：右侧面板 **300ms** 从右淡入 + 轻微位移载入全文。
- 加载中：骨架屏形状与真实文章结构一致（标题条、元信息行、3–5 段落灰条）。

### 8.2 顶部操作条（极窄，固定）

| 按钮 | 功能 | 图标语义 |
|------|------|----------|
| 返回 | 移动端正文返回列表；桌面无操作或聚焦列表 | 左箭头 |
| 已读切换 | 切换当前文章已读/未读 | 勾选 |
| 星标 | 切换星标 | 星形 |
| 字号 | 循环小/中/大三档 | A |
| 分享 | 复制文章链接 | 分享 |
| 焦点模式 | 进入全屏阅读（P3） | 四角扩展 |

- 初始状态：**半透明**（opacity 0.6），随阅读区下滚逐渐变为完全不透明（opacity 1）。
- 高度：40px，不抢占阅读空间。

### 8.3 文章头部

- 标题：大号衬线，见 §4.5。
- 元信息行：来源名 · 相对时间 · 预计阅读时长（按 200 字/分钟估算）。
- 标签行：可点击过滤，来自自动提取 + 手动添加。

### 8.4 正文

- 独立滚动容器。
- 默认衬线字体，行高随设置档位。
- 外链：下划线 accent，新标签打开。
- 图片：最大宽度 100%，懒加载；离线时显示缓存图或占位。

### 8.5 全文提取

| 状态 | 用户可见行为 |
|------|----------------|
| 成功 | 展示提取后的干净 HTML/排版正文 |
| 降级（仅摘要） | 展示 RSS 摘要 + 底部提示条：「无法提取全文」+ 按钮「打开原文」 |
| 失败 | 同上，并记录 `extractStatus: failed` |

### 8.6 焦点模式（P3）

- 一键隐藏左右栏，阅读区扩展至全屏。
- 背景：当前主题色 + `blur(24px)` 虚化遮罩。
- 顶部保留极窄操作条；显示「Exit Focus Mode」入口。
- 退出后恢复三栏布局，**滚动位置保持不变**。

### 8.7 文字选中与批注

**选中任意文字**（P8）弹出浮动菜单：

| 操作 | 结果 |
|------|------|
| 高亮 | 半透明青灰背景持久化 |
| 写批注 | 打开右侧批注侧栏（P9），可输入备注 |
| 复制 | 写入剪贴板，内联「已复制」微反馈 |

批注在正文中以 **数字角标**（1、2…）标记；悬停显示预览；侧栏按时间倒序列出（P9）。

## 9. 智能与组织特性

### 9.1 智能分组（v0.3，v0.1 为手动规则）

- 本地轻量模型，**无需联网**。
- 按主题聚类，示例：技术前沿、深度长文、轻快简讯。
- 用户可：重命名分组、调整成员源、创建关键词规则组。

### 9.2 今日摘要（v0.3）

- 输入：过去 24h 未读 + 星标或高互动文章。
- 输出：≤3 句连贯中文/英文摘要（跟随界面语言）。
- 每日 0:00 本地时区刷新；可手动重新生成。

### 9.3 标签

- 自动：从标题+摘要提取关键词（Top 5）。
- 手动：阅读面板添加，侧栏标签云同步。
- 点击标签：过滤文章列表。

### 9.4 自然语言过滤（v0.3）

搜索框支持口语化查询，示例：

- 「显示上周关于系统设计的文章」
- 「未读的 AI 相关长文」
- 「The Verge 最近三天」

无需记忆查询语法；v0.1 仅支持关键词 + 来源 + 时间范围表单化过滤。

### 10.3 数据

### 10.4 关于

- 版本号、开源许可、隐私说明（本地优先，无默认上传）。

## 11. 离线与数据管理

### 11.1 PWA

- 可安装；初次加载后缓存界面壳。
- **最近 100 篇**文章全文与文内图片可离线阅读。
- 无网络时：可读、可标注、可搜索本地索引；不可拉取新文章。

### 11.2 本地存储（IndexedDB）

存储范围：

- 文章元数据与正文 HTML
- 订阅源与分组
- 阅读进度、高亮、批注、标签
- 用户设置
- AI 模型缓存元数据（v0.3）

### 11.3 OPML 导入（P6）

- 拖拽 OPML 到任意界面触发导入流程。
- 预览清单：勾选要导入的源，显示站点名 + URL。
- 主按钮：「Import (N)」，N 为已选数量。
- 支持取消。

### 11.4 导出

| 类型 | 内容 |
|------|------|
| 全部数据 JSON | 源、文章、高亮、批注、设置、标签 |
| 带标注文章 | 仅含 highlight/annotation 的文章子集 |

## 12. 反馈与状态

| 状态 | 表现 | 位置 |
|------|------|------|
| 源长时间未更新 | 源名称旁 **2px 淡点**（`--text-muted`） | 左侧栏 |
| 连续抓取失败 | **细线感叹号**图标，可点击查看错误/移除 | 左侧栏 |
| 加载中 | 骨架屏，形状匹配真实内容 | 列表、阅读区 |
| 标为已读 | 指示线消失 + **160ms 微闪** | 列表项 |
| 加星 | 星标 **120ms 轻弹** scale | 列表项 / 操作条 |
| 操作成功 | 内联文字反馈，**不用 Toast**（除销毁性操作） | 就地 |

## 13. 非功能性需求

### 13.1 性能

| 指标 | 目标 |
|------|------|
| 首屏可交互 (TTI) | ≤2s（桌面，良好网络） |
| 1000+ 文章列表滚动 | ≥58 fps |
| 主题切换 | ≤100ms，无布局跳动 |
| AI 推理 | 不阻塞主线程，后台 Worker |

### 13.2 可访问性

- 对比度：正文与背景 ≥4.5:1（WCAG AA）。
- 全面键盘可操作（见交互文档）。
- 焦点环：2px `--accent` 外描边。
- 支持 `prefers-reduced-motion`：动效时长减半或关闭位移。

### 13.3 隐私与安全

- 默认不向第三方发送阅读内容。
- 全文提取代理（若启用）由用户自配置 endpoint。
- 导出文件不含明文密码；API Key 仅存本地加密存储（v0.4 同步功能）。
