- 创建 selector 含 prefix/suffix

- 删除高亮级联删除批注

## 4. E2E 关键路径

工具：**Playwright**，浏览器：Chromium（主）、Firefox（每周）、WebKit（发版前）。

### 4.1 路径 E2E-01：首次使用 → 阅读

```typescript
test('import opml, read article, mark read', async ({ page }) => {
  await page.goto('/');
  await page.getByRole('button', { name: /import/i }).click();
  await page.setInputFiles('input[type=file]', 'fixtures/sample.opml');
  await page.getByRole('button', { name: /import \(3\)/i }).click();
  await page.getByText('Sample Feed').click();
  await page.locator('[data-testid=article-item]').first().click();
  await expect(page.locator('[data-testid=reader-title]')).toBeVisible();
  await page.keyboard.press('m');
  await expect(page.locator('[data-testid=article-item]').first())
    .not.toHaveClass(/unread/);
});
```

### 4.2 路径 E2E-02：高亮与批注

1. 打开含正文文章
2. 拖选文字 → 点击 Highlight
3. 再次选中 → Annotate → 输入批注保存
4. 刷新页面
5. 断言高亮与侧栏批注仍存在

### 4.3 路径 E2E-03：离线阅读

1. 在线打开 3 篇文章（触发缓存）
2. `context.setOffline(true)`
3. 刷新应用
4. 断言壳加载、3 篇可打开阅读面板
5. 断言抓取新文章按钮禁用或提示离线

### 4.4 路径 E2E-04：数据导出

1. 创建高亮
2. 设置 → Export annotated JSON
3. 解析下载文件 JSON schema
4. 断言 `highlights.length >= 1`

### 4.5 路径 E2E-05：焦点模式

1. 打开文章滚动至中部
2. 按 `f`
3. 断言侧栏不可见
4. 按 `Escape`
5. 断言滚动位置误差 <5px

## 5. 视觉回归测试

### 5.1 基线矩阵

| 维度 | 取值 | 截图命名 |
|------|------|----------|
| 主题 | dark, warm, cold | `{theme}-` |
| 列表视图 | compact, cards, titles | `{view}-` |
| 状态 | unread, read, starred | `{state}-` |
| 页面 | main(P1), reader(P2), focus(P3), settings(P5) | 后缀 |

示例：`dark-compact-unread-main.png`

共计：**3 × 3 × 3 + 4 固定页 ≈ 31** 张基线（可按版本增减）。

### 5.2 配置

```typescript
await expect(page).toHaveScreenshot('dark-compact-unread-main.png', {
  maxDiffPixelRatio: 0.01,
  animations: 'disabled',
});
```

- CI 中 `--update-snapshots` 仅 maintainer 合并时执行。
- 字体加载：测试前 `document.fonts.ready`。

### 5.3 禁止回归项（人工 Review 清单）

- 出现 `box-shadow` 装饰阴影
- 出现旋转 loading 图标
- accent 色大面积背景
- emoji 图标

## 8. CI 流水线建议

```yaml
# .github/workflows/ci.yml（示意）
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pnpm install
      - run: pnpm lint && pnpm typecheck

  unit:
    needs: lint
    runs-on: ubuntu-latest
    steps:
      - run: pnpm test:unit --coverage

  e2e:
    needs: unit
    runs-on: ubuntu-latest
    steps:
      - run: pnpm build
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:e2e

  visual:
    needs: e2e
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    steps:
      - run: pnpm test:visual
```

### 8.1 分支策略

- `main`：全量 CI + 视觉基线比对
- PR：lint + unit + e2e（Chromium）
- Nightly：Firefox/WebKit + 性能基准
